# Smooth Criminal — Snake Game

Добро пожаловать игрок. В этой игры тебе нужно поймать “гладкого преступника”. 
Но вот не задача, каждый раз, когда ты у него на хвосте, он неожиданно исчезает 
и появляется на другом месте, не просто так его назвали “гладким преступником”.
Чтобы остановить его, тебе нужно изнурить его и тогда он больше не сможет сопротивляться тебе и сдастся. 
Для победы тебе нужно набрать 100 очков. Удачи!

P.S. Эта игра разработана на основе игры “Змейка”, все документация к игре написана с соответствии этой игры.

---

Welcome, player. In this game, you need to catch the ‘Slick Criminal’. 
But here’s the catch: every time you’re hot on his heels, he suddenly vanishes 
and reappears somewhere else – there’s a reason he’s called the ‘Slick Criminal’.
To stop him, you need to wear him down; then he won’t be able to resist you any longer and will give up. 
To win, you need to score 100 points. Good luck!

P.S. This game is based on the game “Snake”; all documentation for the game has been written in accordance with that game.

---

## Управление / Controls

| Клавиша | Действие |
| ------- | -------- |
| `W` / `↑` | Вверх / Up |
| `S` / `↓` | Вниз / Down |
| `A` / `←` | Влево / Left |
| `D` / `→` | Вправо / Right |
| `Esc` | Выход / Quit |

## Запуск игры / How to run

### Требования / Requirements

- Python 3.8+
- pygame

### Установка зависимостей / Install dependencies

```bash
pip install -r requirements.txt
```

### Запуск / Run

```bash
python main.py
```
